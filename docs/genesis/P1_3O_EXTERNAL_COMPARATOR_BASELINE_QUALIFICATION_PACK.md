# PROMETHEUS P1.3O — External Comparator Baseline Qualification Pack

Status: **PREPARED — EXECUTION BLOCKED UNTIL REAL NEIGHBOR CANDIDATE(S) ENTER P1.3N**  
Date: 2026-09-30

## 1. Purpose

Prepare the identical baseline-qualification workflow to be executed on Genesis and each surviving external neighbor candidate before comparator freeze.

This pack is method preparation only. It does not authorize confirmatory sampling coordinates before comparator geometry is selected.

## 2. Baseline qualification blocks

### O1 — Site and geometry
For Genesis and each candidate record:
- boundary/polygon version;
- usable sampling area;
- coordinate system state;
- topographic position;
- slope/aspect;
- hydrological relationship;
- exclusions and access corridors.

### O2 — Soil profile
Record:
- visible/augered profile description where permitted;
- approximate horizons/depths;
- texture evidence;
- coarse fragments/rock;
- imported fill/soil evidence;
- management disturbance;
- parent-material evidence where available.

### O3 — Infiltration method qualification
Before confirmatory baseline freeze:
- choose one repeatable apparatus/method;
- freeze water head or fixed volume;
- freeze antecedent-moisture rule;
- freeze repeat/termination rule;
- define operator QA;
- define field validity flags;
- record rainfall/irrigation context.

### O4 — Aggregate-stability qualification
Freeze:
- sample depth;
- collection geometry;
- field vs laboratory method;
- preparation/moisture handling;
- sieve/method reference;
- replicate/composite rule;
- unit and QA.

### O5 — SOC qualification
Freeze:
- depth increment(s);
- sample/composite rule;
- laboratory method;
- resampling/geolocation rule;
- bulk-density method if stock is to be estimated;
- chain-of-custody/evidence reference.

### O6 — Companion covariates
Collect identically:
- soil moisture;
- ground cover;
- vegetation structure;
- recent management/disturbance;
- weather/rainfall context;
- irrigation status;
- topographic/hydrological position.

## 3. Temporal matching

Genesis and comparator qualification observations should be collected:

- as close in date/time as practicable;
- under comparable seasonal conditions;
- with antecedent rainfall/irrigation recorded;
- without silently mixing substantially different moisture states.

If temporal equivalence is not achieved, the difference must be logged and modeled/interpreted as a limitation.

## 4. Sampling-location rule

During qualification, temporary exploratory points may be used only if explicitly labeled `FEASIBILITY_ONLY`.

Confirmatory sampling coordinates remain blocked until:

1. comparator polygon is selected;
2. strata are frozen;
3. sampling-unit dimensions are fixed;
4. precision/power rationale is documented;
5. coordinates are versioned before outcome interpretation.

## 5. Pseudoreplication control

Multiple samples from one field do not create multiple independent field-level treatment replicates.

The final analysis must distinguish:

- field/reference unit;
- stratum;
- sampling point;
- technical/analytical replicate;
- repeated temporal observation.

## 6. Baseline matching decision table

For each candidate, compare Genesis and candidate on:

- soil/profile;
- parent material;
- elevation/topographic position;
- slope;
- aspect/exposure;
- hydrologic position;
- management/disturbance history;
- vegetation/ground cover;
- primary endpoint baseline levels.

Material differences do not automatically invalidate a candidate, but must be quantified and may downgrade it from EXT-A to EXT-B/EXT-C or REJECTED.

## 7. Qualification-to-freeze rule

After at least one real candidate is measured:

- reject obvious mismatches;
- retain viable candidates;
- classify EXT-A / EXT-B / EXT-C;
- freeze the primary comparator set before post-treatment outcome inspection;
- generate strata and sample-count rationale;
- then freeze confirmatory coordinates.

## 8. Required artifacts at execution

P1.3O execution shall create:

- candidate field sheet;
- geometry file/reference;
- access/permission record;
- photo/evidence index;
- raw baseline observations;
- lab chain-of-custody where applicable;
- QA flags;
- disturbance ledger;
- baseline matching matrix;
- comparator selection record.
