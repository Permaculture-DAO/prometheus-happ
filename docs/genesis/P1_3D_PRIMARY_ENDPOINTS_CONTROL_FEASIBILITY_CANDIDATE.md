# PROMETHEUS P1.3D — Genesis Primary Endpoints & Control Feasibility Decision Protocol

Status: **CANDIDATE — DECISION PROTOCOL FROZEN; FIELD FACTS REQUIRED FOR ENDPOINT/CONTROL FREEZE**  
Date: 2026-09-30

## 1. Objective

Convert the P1.3C outcome domains into a minimal set of defensible primary endpoints and determine whether a contemporaneous untreated control can be maintained inside the 3360.875 m² Genesis ExperimentalSystemBoundary without materially compromising the intervention or the control.

## 2. Primary-outcome selection rule

A primary endpoint must satisfy all six gates:

1. **Relevance** — directly tests a preregistered Genesis mechanism/outcome.
2. **Responsiveness** — plausible sensitivity within the planned observation horizon.
3. **Repeatability** — written SOP and bounded operator/instrument variability.
4. **Comparability** — measurable with the same method in treatment and reference units.
5. **Auditability** — raw observations, provenance, QA and transformations can be retained.
6. **Statistical identifiability** — sampling/replication supports an estimand with uncertainty.

Failure of any gate keeps the metric secondary/exploratory.

## 3. Candidate primary endpoint set

The preferred minimal candidate set is one endpoint per complementary functional domain:

### PE-01 — Water infiltration response

Candidate metric: infiltration rate or time-to-infiltrate a fixed water depth using one frozen field method.

Rationale: responsive physical/hydrologic indicator; repeated spatial measurements can be collected in treatment and control/reference units.

Freeze requirements: apparatus/SOP, antecedent moisture rule, water volume/head, repeat rule, location protocol, unit, QA and weather/disturbance conditions.

### PE-02 — Soil aggregate stability

Candidate metric: water-stable aggregate measure using a frozen laboratory or standardized field method.

Rationale: physical soil structure indicator linked to infiltration, erosion resistance and soil functioning.

Freeze requirements: sample depth, preparation, sieve/method, moisture handling, replicate/composite rule, laboratory/SOP and unit.

### PE-03 — Soil organic carbon

Candidate metric: SOC concentration and, only if bulk density/depth are measured appropriately, SOC stock.

Rationale: important carbon-cycling/soil-state endpoint but expected to change more slowly than some functional indicators.

Freeze requirements: fixed depth increments, sampling/compositing rule, dry-combustion or other declared laboratory method, bulk-density method if stock is claimed, geolocation and resampling rule.

**Temporal classification:** PE-01 and PE-02 are candidates for nearer-term response monitoring; PE-03 is a longer-horizon endpoint and must not be promoted as short-term evidence merely because a numerical change appears.

Vegetation/ground-cover metrics remain secondary until the actual intervention/planting design and image/field SOP are frozen; they may later replace or complement a primary endpoint through a preregistration amendment made before outcome inspection.

## 4. Untreated internal-control feasibility test

An internal control is admissible only if all criteria below are satisfied before intervention.

### C1 — Sufficient area

After excluding edge/buffer, access, infrastructure and unusable zones, the candidate control must support the required independent sampling units and repeated access without destructive overlap.

No fixed percentage of the 3360.875 m² is imposed before sampling-unit dimensions and variance/power rationale are known.

### C2 — Baseline comparability

Treatment and control must be evaluated for material baseline differences in:

- topographic position;
- slope/aspect;
- soil texture/type where available;
- prior management/disturbance;
- vegetation/ground cover;
- hydrologic position;
- frozen primary endpoints.

Perfect equality is not required; material imbalance must be measured and handled in design/analysis.

### C3 — Spillover isolation

The control must be protectable from the focal treatment and indirect effects, including water redistribution, amendments, roots/canopy where material, traffic, irrigation, nutrient movement and management operations.

A spatial buffer must be defined from the actual intervention mechanism, not chosen arbitrarily.

### C4 — Operational durability

The project must be willing and able to keep the control untreated for the entire preregistered primary comparison window.

If operational needs make later treatment likely, that date/window must be declared in advance.

### C5 — Ethical/agronomic acceptability

Maintaining the control must not create unacceptable site degradation, safety problems, or unavoidable management conflicts. Necessary protective actions must be documented and assessed for whether they invalidate “untreated” status.

## 5. Decision rule

- If C1–C5 all pass: freeze an **internal contemporaneous control polygon** and use matched/stratified sampling.
- If any critical criterion fails: do not manufacture an internal control. Use a **matched external reference**, plus repeated pre-intervention baseline within the Genesis boundary.
- If both are feasible: retain the internal control as the principal contemporaneous comparison and the external reference as contextual/robustness evidence.

## 6. Recommended design form if internal control passes

Prefer blocked/stratified treatment-control allocation across comparable terrain positions rather than one convenient corner, when operationally compatible with the intervention.

The final layout must account for spatial autocorrelation and avoid treating subsamples within one management unit as independent experimental replication.

## 7. Precision/power gate

Before fixing sample count:

1. define the minimum effect or precision target that would be scientifically meaningful;
2. obtain variance information from pilot/baseline measurements or defensible external evidence;
3. account for repeated measures and spatial clustering;
4. calculate or justify replication;
5. preserve a distinct feasibility/pilot phase if baseline data are used to design the confirmatory phase.

Sample count must not be reverse-engineered to fit a desired conclusion.

## 8. Required field decision sheet

Before P1.3D promotion, record:

- intervention description and spatial footprint;
- whether any portion can remain untreated, and until when;
- machinery/access paths;
- irrigation/water-flow design;
- planned earthworks;
- planting/canopy/root-spread considerations;
- amendment/fertilizer/compost distribution;
- candidate control polygon;
- buffer rationale;
- baseline sampling observations;
- primary comparison window.

## 9. Promotion criteria

P1.3D becomes **FROZEN** only when:

- final primary endpoint(s) are named with complete SOPs;
- internal-control decision is documented;
- comparator geometry is frozen;
- terrain layer is verified;
- baseline calendar is fixed;
- precision/replication rationale is approved;
- sampling coordinates are generated and versioned.

## 10. Claim boundary

This protocol governs endpoint and comparator selection. It is not evidence that the Genesis intervention works and does not establish ecological truth, certification, legal/market admission or PRU/TRBK value.
