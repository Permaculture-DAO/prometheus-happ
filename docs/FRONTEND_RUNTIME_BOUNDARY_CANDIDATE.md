# Frontend and Holochain runtime boundary candidate

The proposed `prometheus-ui` repository is a presentation and operator interaction layer. It may call the Holochain app interface and the bounded runtime API, but it is not an evidence authority.

The UI must display:

- source and data class;
- QA state;
- uncertainty;
- Holochain receipt/action hash where applicable;
- review state;
- correction lineage;
- claim maturity and permitted wording.

A dashboard view cannot convert a datum into validated evidence or a value-analysis result into a legal or financial right.
