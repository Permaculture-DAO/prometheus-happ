# ADR-MRF-011 — Frozen Model Binding and Oracle Independence (candidate)

Date: 2026-10-21 · Source: PRM-SRC-MRF-ZOME-EDGE-001 (candidate, not ratified)
Parent gates: [#41](https://github.com/Permaculture-DAO/prometheus-happ/issues/41), [#42](https://github.com/Permaculture-DAO/prometheus-happ/issues/42).
Scope: experimental/mrf-kernel-lab ONLY; no signed runtime/DNA, deployment, active Canon or REAL persistence changes.

## Problem and decision
Previously the integrity-zome's receipt check compared a **claimed digest string** to an admitted string, without binding the computation to the actual bytes of the model used in the interpreter. The new experimental callback computes SHA-256 of the canonical PMRF-BIN-v1 bytes generated by the baked toy model and ensures this matches the frozen admitted digest, then compares the receipt digest to that computed value. Fail closed if the compiled toy model changes unexpectedly.

This is a TEST-only *in-code model binding*, NOT a proof that the deployed, signed DNA was reconstructed or that a governance body admitted the model. It reserializes at each verification; optimize only after measuring and without introducing host entropy.

## Verified locally, 2026-10-21
- 10/10 HDI host unit tests passed, including frozen baked-model digest equality, TEST and authority rejection.
- 8/8 synthetic oracle **policy-only** tests passed: agreement candidate, colluding operators, cloned sample, shared payload, missing calibration, stale/revoked status, disagreements and insufficient distinct operators.
- Oracle policy's `signature_verified` and `fresh` fields are *test inputs*, NOT computed cryptographic proofs; passing tests never imply signatures, trusted calibration or true independent custody.

## Remaining blockers and falsifiers
1. Rebuild **new integrity and coordinator WASM**, repackage TEST DNA, record new DNA digest and rerun exact-DNA conductor acceptance/negative tests. Prior conductor PASS applies ONLY to predecessor DNA.
2. Validate all relevant Holochain FlatOp variants (StoreRecord, StoreEntry, RegisterUpdate, RegisterDelete and links) with deliberate mutation/deletion and missing-dependency tests; do not allow untested type paths to silently certify.
3. Test cryptographically authenticated oracle signatures with public keys, binding to payload hash, time/sequence, revocation and replay rejection. Independence of control groups needs independently verified registry/records: three signatures from one owner are not independent.
4. Test conflicts, bad calibration, replay, unavailable peer, network partition, censorship and coherent but physically fraudulent evidence.
5. Benchmark CPU time, memory and energy at real gateway vs simpler signed database/audit trail; retain gate only if complexity earns its cost.
6. Human scientific/governance review and source-admission controls. No REAL, PRU/RAP/TRBK, underwriting/capital or ecological certification.
